# 🛡️ IronMac Homebrew Tap

Official Homebrew Tap for [IronMac](https://github.com/0xaicrypto/ironmac) — Fortress-Grade Web3 & Crypto Workstation Suite for macOS.

## Quick Install

You can install IronMac via Homebrew using either of the following methods:

### Option 1: One-liner (Recommended)

```bash
brew install 0xaicrypto/ironmac/ironmac
```

### Option 2: Tap then Install

```bash
# Add this tap
brew tap 0xaicrypto/ironmac

# Install formula
brew install ironmac
```

### Option 3: Install Latest Development Version (HEAD)

```bash
brew install --HEAD 0xaicrypto/ironmac/ironmac
```

## Post-Installation

Once installed, verify your environment:

```bash
# Verify version
ironmac version

# Run security audit
ironmac audit

# Launch native MenuBar companion shield
ironmac app

# Open zero-trace RAM console
ironmac console
```

## Updating

```bash
brew update
brew upgrade ironmac
```
